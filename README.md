# 📅 Productivity App UI

A modern weekly planning application built with Flutter and Dart, designed to help users organize their schedules, manage activities, and stay productive.

## 📌 About the App

Productivity App UI is a weekly planning application that helps users organize their time and manage their daily and weekly activities.

The app provides a simple and visually appealing interface for planning tasks, tracking progress, and maintaining productive routines.

## ✨ Features

- 📅 Weekly planning
- 📝 Add activities and tasks
- 🗓️ Organize daily schedules
- ✅ Track completed activities
- 📊 Monitor productivity
- 🎨 Modern and clean UI
- 📱 Mobile-friendly design
- ⏰ Manage personal routines

## 🎯 Main Purpose

The main goal of this application is to make weekly planning simple, organized, and enjoyable.

Users can plan their activities, manage their time, and work toward their personal goals through an intuitive mobile interface.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/natanim-samuel/productivity_app_ui.git
   ```

2. Navigate to the project directory:

   ```bash
   cd productivity_app_ui
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
